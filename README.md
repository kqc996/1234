# 供應鏈透明化治理平台

## 專案簡介
這是一個一站式供應鏈透明化治理平台演示系統，包含四大核心模組：

1. **原產地全生命週期溯源** - 從原材料開採到最終消費者的全鏈路不可篡改追溯
2. **供應鏈人權盡職調查** - 穿透供應鏈黑箱，守護勞工人權，杜絕強迫勞動與童工
3. **全鏈路碳排放核算** - 產品碳足跡計算、減排方案建議、CBAM 報告生成
4. **全球貿易法規合規** - 實時同步全球法規，自動筛查風險，降低合規成本

## 使用方式

直接在瀏覽器中開啟 `index.html` 即可使用。

### 快捷鍵
- `Alt + 1~4`: 切換對應模組
- `Alt + ←/→`: 切換上下一個模組

## 技術特色

- **純前端實現**: 無需後端伺服器，靜態頁面即可運行
- **零依賴**: 不使用任何外部框架或函式庫
- **區塊鏈概念演示**: 展示產品溯源數據上鏈的應用場景
- **合規標準整合**: 涵蓋 GOTS、BSCI、UFLPA、CBAM、CSDDD 等國際標準
